Contributing

This project is open to contributions. Keep changes minimal, readable, and consistent with the existing style.
Workflow
1. Fork the repository
2. Create a feature branch
3. Commit changes with clear messages
4. Open a pull request
Rules
- No external frameworks unless required
- Maintain dark, minimal design
- Keep HTML/CSS clean and self-contained
- Avoid unnecessary dependencies
Style Notes
Use monospace, dark backgrounds, and simple layouts. Avoid visual clutter.
