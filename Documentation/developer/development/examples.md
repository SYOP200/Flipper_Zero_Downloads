## App Examples
A collection of examples covering various aspects of app development for Flipper Zero.

- Date/Time Input — Using a date/time input view
- Number Input — Using a simple keyboard that limits user inputs to a full number (integer)
- Application icons — Using images and icons in an app
- Apps Assets folder Example — Using app-specific asset folders
- Apps Data folder Example — Using app-specific data folders
- 1-Wire Thermometer — Reading data from a 1-Wire thermometer
You can find more app examples in the repository on [GitHub](https://github.com/flipperdevices/flipperzero-firmware/tree/dev/applications/examples).
