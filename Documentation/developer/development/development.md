## App Development
Flipper Zero features full support for custom apps, which (usually) do not require any changes to the firmware.

For easy app development, a software tool called uFBT is available.

- [FAP](FAP.md) (Flipper App Package) — Creating apps that can be dynamically loaded from the SD card
- [FAM](FAM.md) (Flipper App Manifests) — How apps announce themselves to the system
- [App Examples](examples.md) — Various app examples, complete with the source code
- [Publishing to the Apps Catalog](publishing.md) — Learn how to publish and update your app in the Apps Catalog

**If you want to publish an app, check out [this](https://github.com/flipperdevices/flipper-application-catalog/blob/main/documentation/Contributing.md)**
