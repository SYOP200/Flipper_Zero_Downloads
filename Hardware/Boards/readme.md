### [Flipper Zero Wifi Devboard](https://lab401.com/collections/flipper-zero/products/flipper-zero-wifi-devboard)
#### INTRODUCTION

The Flipper Zero Wifi devboard brings Wi-Fi connectivity to your Flipper device.

Out of the box the Wifi Devboard adds the following functionality:

- Advanced, in-circuit debugging via USB or Wifi, via Black Magic Probe project
- Wireless / OTA Firmware Updates
  
Internet connectivity on the Flipper opens a world of possibilities, turning your device into an all-powerful controller that slips into your pocket:

- Control and Monitor your IoT devices remotely (Lights, heating, etc)
- Write modules using connected APIs (Twitter, Twilio, etc)
  
Advanced users can take advantage of the board's ESP32-S2 chipset to enable Wi-Fi penetration testing:

- De-auth Attacks / De-auth detection
- PMKID capturing
- Passive packet capture in promiscuous mode

### [Raspberry Pi Pico 2](https://vilros.com/products/raspberry-pi-pico-2?variant=41114605027422&country=US&currency=USD&utm_medium=product_sync&utm_source=google&utm_content=sag_organic&utm_campaign=sag_organic&tw_source=google&tw_adid=&tw_campaign=19684058556&gad_source=4&gad_campaignid=19684058613&gbraid=0AAAAAD1QJAjtOTegH268QTiPjJV0FuGJO&gclid=CjwKCAjw6rfSBhAqEiwA_yocppBKc4NHxI40xLSnt6bkAZ4v9qlYH2wbtNqHpK8r2RESFiKUaRFOchoCYRoQAvD_BwE)
#### INTRODUCTION

Raspberry Pi Pico 2 builds on the huge success of the original Raspberry Pi Pico product and its derivatives, which were launched in 2021 and 2022. It is powered by the brand-new RP235x microcontroller platform, designed here at Raspberry Pi.

In comparison with its predecessor, RP2040, RP235x offers:

- A 150MHz system clock (versus 133MHz)
- Dual Arm Cortex-M33 cores (versus dual Arm Cortex-M0+)
- Dual RISC-V Hazard3 cores
- 520KB RAM (versus 264KB)
- 8KB on-chip OTP storage
- A comprehensive security model, based on Arm TrustZone for Cortex-M
- Greatly improved power efficiency

Raspberry Pi Pico 2 pairs RP2350 with 4MB of on-board QSPI Flash memory (versus 2MB on Raspberry Pi Pico) for code and data storage.
